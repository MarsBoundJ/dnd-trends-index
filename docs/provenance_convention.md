# Provenance convention — how to trace a document back to its source

Every generated artifact carries a block saying what made it, from what, and
when. Hand-written docs carry a lighter version.

**Adopted Sep 2, 2026**, after establishing the provenance of
`arcane/public/reports/ip_deep_dive.html` took twenty minutes of forensics —
grepping for generator meta tags, comparing occurrence counts across two file
formats, and reading three build scripts — to recover four facts that the file
could simply have stated.

---

## The rule that makes this work

**Provenance is emitted by the build, never typed by a human.**

A hand-typed provenance block is another typed claim, and typed claims rot
exactly the way hardcoded numbers do. If someone must remember to update the
block, it will be wrong within a month and worse than absent — because a stale
provenance block is *believed*.

The corollary: if a document has no build step, it gets the short hand-written
form below, and that form deliberately contains **only facts that do not change**
(what it is, who decides, what supersedes it). Anything time-varying belongs in
git history, not in a block someone must maintain.

---

## Generated artifacts (HTML, PDF, docx)

Emitted at build time, at the end of the document:

```
─────────────────────────────────────────────
Generated by : make_html.ps1 (pandoc 3.1.11)
Source       : pitch/report/trusight_breakdowns_scratch.md @ a41184c
Stylesheet   : pitch/report/pdf_style.css
Data as of   : 2026-09-02 (gold_data.fanfic_crossover_rate)
Built        : 2026-09-02T14:22:11Z
Rebuild      : cd pitch/report && ./make_html.ps1
─────────────────────────────────────────────
```

Fields, and why each is there:

| Field | Answers |
|---|---|
| `Generated by` | which of several pipelines produced this |
| `Source` **@ SHA** | *which version* of the source — the field that matters most |
| `Stylesheet` | why it looks the way it does |
| `Data as of` | whether the numbers are current |
| `Built` | how stale the artifact is |
| `Rebuild` | the exact command, so correcting is not archaeology |

`Source @ SHA` is the load-bearing one. Without it you cannot tell a stale
artifact from a current one, which is precisely the state
`ip_deep_dive.html` was in: published in May, source corrected in September, and
nothing on the page said so.

`Rebuild` is second. A correction that requires reconstructing the build command
tends not to happen — which is why PR #103's fix never reached the live site.

## Hand-written docs (design docs, plans, methodology)

Short header, only non-varying facts:

```markdown
**Status:** proposed | accepted | superseded
**Supersedes:** <doc or spec section>, if any
**Owner:** who decides
```

Deliberately no dates or SHAs — git already tracks those, and a hand-maintained
date is a promise to keep updating it that nobody keeps.

---

## Applying it

- **New generator:** emit the block. No exceptions.
- **Existing generator:** add it when next touched.
- **Artifact with unknown provenance:** state `Provenance: UNKNOWN` and what was
  checked. Do **not** guess. An asserted-but-wrong source is worse than an
  admitted gap — a reader acts on the first and investigates the second.

---

## Worked example: what this would have saved

`ip_deep_dive.html`, before:

- Where does it come from? No script references the filename.
- Which markdown? Two candidates, both plausible by name.
- Is it current? Unknown.
- How is it rebuilt? Unknown.

Recovering that took: reading the `<meta name="generator">` tag, counting string
occurrences in both files (and initially miscounting, because `grep -c` counts
*lines* and markdown paragraphs are single long lines while pandoc wraps its
output — that artifact briefly looked like evidence the two files had diverged),
then finding `--metadata 'pagetitle=IP Deep Dive: 19 Licensing Candidates'`
buried in `make_html.ps1` and matching it against the HTML `<title>`.

The answer: pandoc, from `pitch/report/trusight_breakdowns_scratch.md`, via
`make_html.ps1`, output as `trusight_breakdowns.html` and then **manually copied**
to `arcane/public/reports/ip_deep_dive.html` — a rename step recorded nowhere.

Six lines at the bottom of the file would have replaced all of it.
